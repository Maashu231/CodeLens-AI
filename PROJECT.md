# CodeLens AI

## Problem

Large software repositories are difficult for developers to understand.
Developers often spend a lot of time searching through files, functions,
Git history, and dependencies when investigating bugs or understanding
unfamiliar code.

## Solution

CodeLens AI is an AI-powered codebase intelligence system that helps
developers understand repositories, investigate bugs, trace code
relationships, and analyze the possible impact of code changes.

## Main Features

1. Ask questions about a codebase
2. Find relevant code
3. Explain how different parts of the code work together
4. Investigate possible bugs
5. Use Git history as additional context
6. Analyze the impact of code changes
7. Provide evidence for AI-generated answers
